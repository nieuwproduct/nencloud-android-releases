Install

  1. Download the APK on the phone.
  2. If Android blocks the install, allow this browser to install unknown apps: Settings, Apps, Special app access, Install unknown apps, then the browser you used.
  3. Open the APK and install. Later versions install over this one when they are signed with the same key.
  4. Open NenCloud, set the server URL if needed, and sign in with a local username and password.

The app also checks this site’s version.json and offers to download a newer APK itself.
